# نرم‌افزار حسابداری آریو (Ario Accounting)

نسخه ساده و کاربردی حسابداری فارسی برای ویندوز، لینوکس و مک.

## ویژگی‌ها (مشابه هسته نرم‌افزارهای حسابداری فارسی مثل پارسیان)

- **کدینگ حساب‌ها**: تعریف حساب‌های کل، معین و تفصیلی با ساختار درختی
- **ثبت سند حسابداری**: سند دستی چندردیفه با کنترل تراز بودن
- **اشخاص**: مشتریان و تأمین‌کنندگان
- **کالا و انبار**: تعریف کالا، موجودی، قیمت خرید و فروش
- **فاکتور فروش**: ثبت فاکتور + کاهش موجودی + ثبت خودکار سند حسابداری
- **گزارش‌ها**:
  - تراز آزمایشی
  - دفتر روزنامه
  - سود و زیان ساده
- رابط کاربری فارسی و راست‌چین
- پایگاه داده SQLite (بدون نیاز به نصب سرور جداگانه)

## نحوه اجرا در ویندوز

### روش ۱: ساده (پیشنهادی)

1. پایتون ۳.۱۰ یا بالاتر را از [python.org](https://www.python.org/downloads/) نصب کنید (تیک «Add to PATH» را بزنید).
2. این پوشه را باز کنید.
3. روی فایل `run.bat` دوبار کلیک کنید.
4. مرورگر را باز کنید و به آدرس زیر بروید:
   ```
   http://127.0.0.1:5000
   ```
5. ورود با:
   - نام کاربری: `admin`
   - رمز عبور: `admin`

### روش ۲: دستی

```cmd
pip install -r requirements.txt
python app.py
```

## ساخت فایل اجرایی (.exe) در ویندوز

اگر می‌خواهید یک فایل اجرایی بدون نیاز به پایتون داشته باشید:

```cmd
pip install pyinstaller
pyinstaller --onefile --add-data "templates;templates" --add-data "static;static" --name "ArioAccounting" app.py
```

فایل نهایی در پوشه `dist` قرار می‌گیرد.

**توجه:** برای بسته‌ی نصبی حرفه‌ای می‌توانید از Inno Setup یا NSIS استفاده کنید و فایل exe + دیتابیس را بسته‌بندی کنید.

## تفاوت با پارسیان

این نرم‌افزار یک **نسخه سبک و آموزشی/کاربردی** است و شامل تمام ماژول‌های پیشرفته پارسیان (حقوق و دستمزد کامل، تولید، بهای تمام‌شده، چک‌های پیشرفته، چندانباره، پورسانت ویزیتور، شبکه چندکاربره سنگین و ...) نیست. ساختار و ظاهر کلی شبیه نرم‌افزارهای حسابداری فارسی طراحی شده تا کاربر آشنا باشد.

## توسعه بیشتر

در صورت نیاز می‌توانید درخواست اضافه کردن ماژول‌های زیر را بدهید:
- چک و بانک پیشرفته
- فاکتور خرید + برگشت از فروش
- حقوق و دستمزد پایه
- چند کاربره با سطح دسترسی
- خروجی اکسل و گزارش‌ساز
